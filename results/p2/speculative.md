## 观测与边界

本工作负载全部接受率为 1；无衰减观测，不人为改坏草稿。
全部 k、两批次相对 fp32 均无 p50 加速，是合法负结果。
解析模型的可行性及阈值逐 k 列于前表；不能将高接受率等同于收益。

CPU 实测，约 0.5M 同源小模型；草稿仅 block Linear 为 INT8，每次反量化后 fp32 matmul，没有整数算子加速；激活、KV、embedding/tied head 均为 fp32。草稿–验证同源导致接受率虚高，不可外推到大模型或异源草稿；不得人为改坏草稿。逐 token 硬门槛仅覆盖规定矩阵，不承诺全 prompt 的无条件数值等价。全接受观测点不能确定接受率下降时的真实曲线；解析曲线假设逐位独立、恒定接受概率，不是人工降质实测。盈亏平衡模型忽略 prefill、终止轮、cache 截断/同步和 Python 开销，使用代表性前缀的组件 mean，属于乐观成本模型，不要求 D<T。端到端包含两模型 prefill、真实自回归、验证、同步、截断、日志及最终输出；EOS 关闭，预算耗尽不出 bonus，终止轮短于 k 时照实记录。滑窗区间单独统计 fp32 target-only；窗口内收益不外推到窗口外。measure() 原协议，含 tracemalloc 开销；峰值仅增量 Python 追踪，漏原生内存，RSS 是进程生命期高水位且模型共存，均不构成模型内存压缩证据。两个相反顺序批次，无置信区间；T4 为历史经验分辨参照，超过阈值不自动证明显著性。
