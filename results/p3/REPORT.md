## 背压行为

全网格共7614次计划到达，成功2680，429拒绝1579，客户端满3355；超时、503与传输错误均0。
客户端以 C 个预启动线程/最多 C 个 socket 组成有界连接池；服务固定 `Connection: close`，
因此每请求重连。连接/读取超时10s，服务 socket 超时10s；HTTP workers=128、pending=0，
大于最大C，避免把 HTTP 处理器容量作为推理队列背压。客户端满时立即丢弃，无隐藏 executor 请求队列或重试。

C=1 时 Q 不起作用，160/s 两个Q点分别丢弃774/768次，尾时延仅约45–51ms；这是客户端门控，
不能据此判断服务可承受160/s。Q=2、C=8/64 在10/s已经观察到2/3次429；Poisson 突发在低平均负载
也能碰到小队列，首429点不是持续过载点。160/s、C=64、Q=2 拒绝754/921次，成功请求 p99=159.010ms。
相同 λ/C 的 Q=64 没有429，p99却升至2173.525ms，并有559次客户端满。
C=64限制在途请求数，因此Q=64的推理等待队列最多约63，客户端池会先限流；无429不表示无背压。

40/s、C=64 时，Q=2成功173/264、拒绝91，p99=117.925ms；Q=64排空后264/264成功，
但窗口 req/s 只有28.833，p99=1049.353ms。较长队列在本配方中以积累等待换取更少拒绝，
不能把更高的排空成功率描述成窗口吞吐提升或稳定性改善。

## 偏差分析

使用已入库 P1-T4 校准模型（[来源与限制](../p1/REPORT.md#模拟–实测校准)），
固定 prefill 斜率0.009386012640 ms/token、decode(1)=0.5257505ms；未用本次 HTTP 数据重新拟合。
校准源文件 SHA-256 `b413cf026ee28e9492c52c95e4416045f5760ff9d6fd7f4a46714f9fa6f658e4`。
脚本先以 static B=1、batch_timeout=0 运行原 T3，再用串行 FIFO 适配器重放；去掉 C 上限时，
18个点的完成/拒绝、p50/p95/p99及雪崩判定全部与T3一致。独立测试还核对时间加权队长与斜率。
适配器增加有限 C、相同 Q、客户端超时；两侧请求时刻/长度/seed/到达率/窗口一致，
HTTP worker、socket传输等真实机制由模拟零开销假设替代，未声称逐请求完成时刻一致。
原 T3 无限客户端结果另外存于每点 `nominal_t3_summary.json`，有限C结果在 `simulation.json`。

p99相对偏差定义为(模拟−实测)/实测，18点均为低估，范围约−60.85%至−10.55%。
40/s、C=64、Q=64低估60.85%，160/s同C/Q低估23.86%。
前一点模拟窗口吞吐38.5req/s，实测28.833req/s，模拟高估约33.53%；
高负载下服务时间误差累积为等待时间偏差，临界位置可能明显移动。
Q=2、C=64、160/s模拟单轮拒绝227/307，实测三轮754/921（均值251.333/307），
不能直接拿模拟单轮计数和实测三轮计数相减。

prefill拟合固定截距约0.5143ms在T3中仍省略，decode只在context=32标定；
T3成本为prefill+N次decode，而真实cached生成的首token来自prefill，之后N−1次decode。
此外HTTP解析/传输、GIL、线程调度、同进程负载生成/队长采样与tracemalloc均影响实测，
不能将残差全部归因于网络或客户端。固定种子不消除OS调度或顺序漂移。

客户端开销独立保存在每轮 summary：dispatch 延迟、调用线程 CPU 时间、
transport residual=wire−queue_wait−inference。后者还含服务 HTTP/传输开销，不是纯客户端成本。

## 边界声明

只适用于 Apple M4 Max CPU、小模型、单进程串行推理、loopback、无 TLS。
未测MPS、CUDA、多卡、多进程、跨机网络或生产服务；负载线程与HTTP处理线程不代表并行模型推理。
流式正确性与TTFT来自T1，本次T2负载扫描仅整包，不测慢SSE消费者的过载雪崩曲线。
连接逐请求新建，无keepalive；HTTP理想模型不能覆盖TCP/线程/反向代理/负载均衡开销。
队列有界、C有限，低尾时延可以伴随高拒绝/客户端丢弃；成功分位数不覆盖失败请求。
超时计数为0只限本配方，不能当作超时策略的实验验证。模拟为预测，实测为本机工程证据；
无独立进程重复或置信区间，smoke test 不等于实验证据，也不作生产级容量结论。
